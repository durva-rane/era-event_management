# ERA architecture note

ERA is a Flask application organized as feature blueprints. Routes handle HTTP input/output and call feature services; services own authorization-sensitive business workflows and use the shared MySQL cursor context manager. `get_db_cursor` commits after a successful service operation and rolls back on exceptions. InnoDB row locks serialize venue selection and vendor confirmation before records are created or transitioned. Read-heavy dashboards and reports aggregate in SQL, with bounded list endpoints and supporting composite indexes.

The main feature areas are `auth`, `events` (venues, events, schedules and venue bookings), `vendors` (profiles, services, vendor bookings, chat and reviews), `finance` (budgets, invoices, payments and gateways), `attendees`, `notifications`, `delivery`, `dashboard`, and `reports`. `core` contains configuration, authentication decorators, database transaction management, CSRF validation, pagination, domain errors, and the notification entry point. `notification_service` persists in-app notifications in the caller transaction and dispatches SMTP/SMS adapters asynchronously.

Booking status changes that affect invoices, payments, budgets, or cancellations are called from feature services within the caller's database transaction. This keeps data changes atomic; external payment gateway calls use gateway adapters, and gateway verification is idempotent per transaction. Notifications/audit writes are made through shared service helpers. Avoid issuing feature-specific SQL from routes; when a feature needs another module's behavior, call its public service API and keep related writes inside the passed transaction cursor.

Production runs behind HTTPS with explicitly trusted proxy hops, strong environment-provided secrets, secure session cookies, CSRF checks on unsafe methods, parameterized SQL, and generic unexpected-error responses. The legacy browser app still has inline scripts, so the current CSP includes `unsafe-inline`; this is the remaining hardening item before a strict CSP can be enabled.
